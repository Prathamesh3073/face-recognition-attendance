# 🎓 Face Recognition Attendance System

## 📌 Description
A real-time face recognition system that marks attendance automatically using OpenCV.

## 🚀 Features
- Capture face dataset
- Train recognition model
- Real-time face recognition
- Automatic attendance logging
- Web dashboard integration (optional)

## 🛠 Tech Stack
- Python
- OpenCV
- NumPy

## ▶️ How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Capture dataset:
python capture.py

3. Train model:
python train.py

4. Run recognition:
python recognize.py

## ⚠️ Note
Dataset and trained model are not included in the repository.
